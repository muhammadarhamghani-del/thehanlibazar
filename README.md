## 🚀 How to Run Locally

```bash
# 1. Navigate to the website directory
cd thehanlibazar-website

# 2. Install dependencies (if not already installed)
npm install

# 3. Start local development server
npm run dev

# 4. Build production bundle for deployment
npm run build

# 5. Preview the production build locally
npm run preview
```

## 🌐 How to Upload to GitHub and Host Live

### Step 1: Upload to GitHub

1. Open your terminal / PowerShell in `thehanlibazar-website`:
   ```bash
   cd "C:\Users\arham\Desktop\The Hanli Bazar\thehanlibazar-website"
   git init
   git add .
   git commit -m "Launch The Hanli Bazar 3D website"
   ```

2. Create a new repository on [github.com](https://github.com) named `thehanlibazar` (or `thehanlibazar-website`).

3. Link and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/thehanlibazar.git
   git push -u origin main
   ```

---

### Step 2: Connect to Hosting (Zero Config)

#### Option A: Vercel (Recommended — 2-minute 1-click setup)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New Project"** and select your `thehanlibazar` repository.
3. Keep default settings:
   - Framework Preset: **Vite**
   - Root Directory: `./`
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. Click **Deploy**. Your site will be live instantly!

#### Option B: Netlify
1. Go to [netlify.com](https://netlify.com) and connect your GitHub repository.
2. Set Build command to `npm run build` and Publish directory to `dist`.
3. Click **Deploy Site**.

#### Option C: Cloudflare Pages
1. In the Cloudflare Dashboard, go to **Workers & Pages** > **Create application** > **Pages** > **Connect to Git**.
2. Select your repository, choose the `Vite` preset, and deploy.

---

### Step 3: Connect Your Custom Domain (`thehanlibazar.com`)

1. In your hosting provider (e.g. Vercel / Netlify / Cloudflare):
   - Go to **Project Settings** > **Domains**.
   - Type `thehanlibazar.com` and `www.thehanlibazar.com` and click **Add**.
2. Vercel/Netlify will display the exact DNS records to add:
   - **Type A Record:** `@` points to `76.76.21.21` (for Vercel)
   - **CNAME Record:** `www` points to `cname.vercel-dns.com`
3. Log in to the domain registrar where you purchased `thehanlibazar.com` (GoDaddy, Namecheap, Google Domains / Squarespace, Hostinger, etc.).
4. Open **DNS Management** for `thehanlibazar.com`, add the A and CNAME records, and save.
5. Your custom domain will automatically receive a free SSL certificate (HTTPS) within 15–30 minutes!
